# Как решить задачу № 27 ЕГЭ: выбираем три числа

В задаче № 61407 требуется выбрать три числа из последовательности так, чтобы их сумма была максимально возможной. При этом разность индексов самого правого и самого левого из трёх выбранных элементов должна быть не меньше `2 * K`.

Разберём условие на примере, затем напишем эффективную программу.

## 1. Что дано в условии

Входной файл содержит:

- `K` — параметр ограничения на расстояние;
- `N` — количество чисел;
- `N` целых чисел последовательности.

Расстояние между элементами — это разность их порядковых номеров. В Python удобнее использовать индексы, начинающиеся с нуля: разность индексов равна разности порядковых номеров.

Например, если `K = 2`, требуемое расстояние равно:

`2 * K = 4`.

Нужно выбрать три элемента с разными индексами так, чтобы хотя бы две выбранные позиции отличались минимум на четыре.

## 2. Разбираем пример вручную

Последовательность:

```python
numbers = [6, 7, 8, 2, 3, 5]
```

Индексы элементов:

| Индекс | Значение |
|---:|---:|
| 0 | 6 |
| 1 | 7 |
| 2 | 8 |
| 3 | 2 |
| 4 | 3 |
| 5 | 5 |

Подходящий выбор:

- `numbers[1] = 7`;
- `numbers[2] = 8`;
- `numbers[5] = 5`.

Расстояние между крайними позициями:

`5 - 1 = 4`.

Ограничение выполнено, потому что `4 >= 2 * K`.

Сумма:

`7 + 8 + 5 = 20`.

Ответ для демонстрационного примера — **20**.

Почему нельзя просто взять три самых больших числа? Значения `6`, `7` и `8` находятся на позициях `0`, `1` и `2`. Максимальное расстояние между ними равно `2`, а требуется не меньше `4`.

## 3. Как ускорить поиск

Простой перебор всех троек требует порядка `O(N³)` операций. Для большого файла это слишком медленно.

Вместо этого будем перебирать правый элемент тройки. Обозначим его индексом `right`.

Для каждой позиции `right` найдём:

1. `best_old` — максимальное значение среди элементов с индексами от `0` до `right - 2 * K` включительно.
2. Лучший третий элемент — максимальное значение во всей последовательности, индекс которого не совпадает с индексами `best_old` и `right`.

Эти три элемента образуют допустимую тройку: расстояние между `best_old_index` и `right` не меньше `2 * K`. Третье число может находиться в любой позиции, если она не совпадает с двумя выбранными.

### Зачем нужны три максимальных элемента

Заранее сохраним три наибольших элемента последовательности вместе с их индексами.

При выборе третьего элемента исключаем позиции `best_old_index` и `right`. Запрещены не более двух индексов, поэтому среди трёх наибольших элементов обязательно останется хотя бы один допустимый кандидат. Первый подходящий элемент в отсортированном списке `top3` будет наилучшим третьим элементом.

Важно хранить индексы, а не только значения: одинаковые числа могут находиться в разных местах, а одну и ту же позицию нельзя выбирать дважды.

### Почему алгоритм находит максимум

Рассмотрим оптимальную допустимую тройку с индексами `i`, `j` и `right`, где `i < j < right` и `right - i >= 2 * K`.

При обработке `right` позиция `i` входит в диапазон, из которого выбирается `best_old`. Обозначим индекс выбранного максимума через `p`. Тогда `a[p] >= a[i]`.

Возможны три случая:

- Если `p == i`, позиция `j` остаётся допустимым третьим элементом.
- Если `p == j`, позиция `i` остаётся допустимым третьим элементом.
- Если `p` не равен ни `i`, ни `j`, обе позиции `i` и `j` допустимы в качестве третьего элемента.

Алгоритм выбирает лучший допустимый третий элемент. Поэтому в каждом из этих случаев сумма, найденная для `right`, не меньше суммы рассматриваемой оптимальной тройки.

При этом каждая сумма, которую вычисляет алгоритм, допустима: крайние выбранные позиции находятся на расстоянии не меньше `2 * K`, а третий индекс отличается от обоих.

Следовательно, алгоритм не пропускает максимальную допустимую сумму и не выдаёт сумму недопустимой тройки. Значит, найденный ответ оптимален.

## 4. Полный код на Python

```python
k, n, *a = map(int, open("27-A.txt"))

# Сохраняем три наибольших элемента
# вместе с их индексами.
top3 = []

for index, value in enumerate(a):
    top3.append((value, index))
    top3.sort(reverse=True)

    if len(top3) > 3:
        top3.pop()

answer = float("-inf")
best_old = None
best_old_index = -1

# Перебираем правый элемент тройки.
for right in range(2 * k, n):

    # Добавляем новую позицию, которая уже
    # достаточно далеко от right.
    old_index = right - 2 * k
    old_value = a[old_index]

    if best_old is None or old_value > best_old:
        best_old = old_value
        best_old_index = old_index

    # Находим лучшее третье число.
    # Оно не должно совпадать по индексу
    # с двумя уже выбранными элементами.
    for third_value, third_index in top3:
        if (third_index != best_old_index
                and third_index != right):
            candidate = best_old + third_value + a[right]
            answer = max(answer, candidate)
            break

print(answer)
```

## 5. Проверяем алгоритм

Для демонстрационного примера:

```text
K = 2
N = 6
6
7
8
2
3
5
```

Можно выбрать числа `7`, `8` и `5`, находящиеся на индексах `1`, `2` и `5`.

Расстояние между крайними индексами равно `5 - 1 = 4`, то есть `2 * K`. Сумма равна `7 + 8 + 5 = 20`.

Поэтому ответ для демонстрационного примера — `20`.

В исходном условии задачи гарантируется `1 < 2 * K < N`. Следовательно, `K` положительно, а допустимая тройка существует. Поэтому начальное значение `float("-inf")` не останется ответом после завершения алгоритма.

Обрати внимание: используется `float("-inf")`, а не `0`. Это важно, поскольку последовательность может содержать отрицательные числа. Если все допустимые суммы отрицательны, ноль не должен ошибочно стать ответом.

## 6. Оценка сложности

- Время: `O(N)`. Список `top3` содержит максимум три элемента, поэтому его сортировка занимает постоянное время на каждой итерации.
- Дополнительная память: `O(1)`, не считая хранения входной последовательности.

Это значительно эффективнее полного перебора троек за `O(N³)`.
